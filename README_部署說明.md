# class306 GitHub Pages 素材覆蓋包

此包提供網站現用的 16 張同名 PNG，可直接替換班級網站專案內的角色素材。素材對應為：`mali`＝英雄小狗、`gosig`＝金色犬、`panda`＝熊貓、`long`＝藍色飛龍。

## 使用方式

1. 先備份網站專案中原有的 16 張 PNG。
2. 將此 ZIP 解壓到網站 GitHub 專案的素材檔所在位置，允許以同名 PNG 覆蓋。
3. 檢查網站原本的路徑未改變，然後依平常流程提交並推送到 GitHub Pages。
4. 部署完成後在瀏覽器強制重新整理，檢查四個角色的睡眠、睜眼與張嘴狀態。

本包只替換靜態 PNG，不含 HTML/CSS，也不會自動修改或發布你的網站。每張圖都是 RGBA 透明 1920×1920 PNG；同角色各圖層須以原座標直接疊加，不要額外裁切或單層移位。
